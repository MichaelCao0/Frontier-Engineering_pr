# Robotics（机器人工程）

本领域聚焦机器人工程中的开放式优化问题，要求 AI Agent 在满足运动学、动力学与安全约束的前提下优化实际工程目标。

## 背景

机器人优化广泛存在于制造、物流与自主系统中。相比纯数学任务，这类问题更强调物理约束与工程可落地性。

## 任务列表

| 任务 | 描述 | 状态 |

| [RobotArmCycleTimeOptimization](RobotArmCycleTimeOptimization/) | 优化七自由度机械臂轨迹，最小化 pick-and-place 节拍时间 | 已完成 |
| [QuadrupedGaitOptimization](QuadrupedGaitOptimization/) | 优化四足机器人步态参数，最大化前向速度 | 已完成 |
| [DynamicObstacleAvoidanceNavigation](DynamicObstacleAvoidanceNavigation/) | 在动态障碍环境中优化差分轮机器人控制，最小化到达时间 | 已完成 |

## 领域价值

- **RobotArmCycleTimeOptimization** 贴近工业产线效率优化。
- **QuadrupedGaitOptimization** 对应四足机器人运动性能优化。
- **DynamicObstacleAvoidanceNavigation** 反映 AMR 在动态人车混行环境下的导航挑战。
